# AEONFALL — Crafting, Mastery, and Ascension

## Philosophy
The strongest progression must require breadth of mastery, not one repetitive farm.

## Material Ledger
Physical inventory should not hold tens of thousands of individual objects.
Persistent progression stores sparse material counts.

Material families:
- common regional resources
- refined resources
- monster organs
- boss essences
- faction currencies
- event cores
- dimensional materials
- Absolute relic components
- Transcendent components

## Refinement Graph
Raw materials move through staged conversion.

Example:
Void Shard
→ Void Cluster
→ Condensed Singularity
→ Black Star Core
→ Axiom component

Refinement may require:
- quantity
- station
- faction reputation
- world state
- boss clear
- class mastery
- rare catalyst

## Axiom Heart
The Axiom Heart represents tens of thousands of acquired components through nested refinement.

The final craft should require participation across:
- raids
- world bosses
- exploration
- factions
- horde ecosystems
- wildlife
- dungeons
- events
- crafting
- vehicle exploration
- hidden trials
- class mastery

## Zero Candidate
A player only becomes a Zero Candidate after satisfying the full prerequisite lattice.

Suggested prerequisite categories:
- maximum core progression
- multiple mastered classes
- God progression
- Absolute progression
- designated boss clears
- faction mastery
- exploration/discovery
- crafted Absolute relics
- hidden flags

## Ten Ascension Trials
1. Worth
2. Collection
3. Hunt
4. Conquest
5. Unbroken
6. Worldwalker
7. Mastery
8. Sacrifice
9. Impossible War
10. Zero

Every trial has:
- entry requirements
- failure rules
- anti-carry rules where appropriate
- explicit state persistence
- recovery path
- telemetry

## The Choosing
Completing prerequisites grants eligibility, not Transcendence.

The Choosing is a final authored endgame event that tests:
- combat
- survival
- resource management
- mechanical execution
- encounter knowledge
- puzzle solving
- adaptation

It should not be reducible to raw PvP damage output.

## Transcendent Zero
Transcendent Zero is a temporary high-authority combat/world-director state layered over the player’s existing mastery.

Canonical Authorities:
- Axiom Break
- World Devourer
- Omnipresence
- Causality Rejection
- Genesis Engine
- Pantheon
- The Last Word
- Reality Engine

## Persistence Rule
Do not persist giant transient combat states.
Persist:
- qualifications
- mastery
- ownership/history
- durable unlocks
- material ledger
- trial progress
- ascension flags

Rebuild transient runtime state each session.
