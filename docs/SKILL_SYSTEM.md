# AEONFALL — Class, Skill, and Ascension Runtime

## Core Philosophy
Skills must scale by **mechanical authority**, not only damage.

A higher-tier skill earns its tier by changing more of the encounter:
- target selection
- movement
- terrain access
- hazard state
- ally state
- enemy behavior
- event objectives
- time pressure
- resource economy

## Class Structure
Each class has:
- passive identity
- primary resource
- 4 core skills
- 2 specialization skills
- 1 ultimate
- mastery tree
- ascension modifier
- class-specific traversal or defensive language

Players should be able to understand an enemy/ally class from silhouette and effects before reading UI.

## Skill Tier Ladder
### Mortal
Normal class skills with strong tactical identity.

### Epic / Legendary
Skills gain secondary interactions and combo grammar.

### Mythic
Skills begin altering arena state and create multi-step effects.

### Exotic
Mechanics become unusual: reflection, inversion, conditional rule changes, spatial anchors, copied states.

### God
Skills create authored domains with major encounter influence.

### Absolute
Skills temporarily replace local combat assumptions inside bounded spaces.

### Transcendent Zero
Authorities sit outside ordinary class cooldown structure and are only available during authorized Transcendent state.

## Godhood Timer
God/Absolute-style transformation is intentionally temporary.

Recommended runtime model:
- base transformation duration
- actions can extend/shorten duration by authored rules
- clear countdown UI
- escalating audio/visual state
- final 10-second collapse warning
- safe deterministic return to normal class state

No permanent unstoppable combat state.

## Five World-Bending Class Skills

### 1. Heavenfall Vector
**Class:** Gravemancer / Gravity Sovereign
Creates a bounded gravity lattice with multiple vector nodes. Players can rotate local pull directions between authored orientations, launching enemies into hazards or creating traversal routes.

Upgrades:
- Mythic: two vectors
- God: four synchronized vectors
- Absolute: moving vector lattice
- Transcendent synergy: Axiom Break may replace the lattice rule set temporarily

Counterplay:
- anchor pylons can be destroyed
- protected bosses resist full displacement
- lattice orientation is visibly telegraphed

### 2. Epoch Cathedral
**Class:** Chronarch
Builds a temporal arena from recorded combat states. Specific projectiles, hazards, and destructible cover can replay authored echoes at timed intervals.

This is not literal global time travel. It is a deterministic encounter system that records approved states.

Upgrades:
- Mythic: replay one object group
- God: layered replay tracks
- Absolute: choose which track is accepted or rejected
- Transcendent synergy: Causality Rejection gains additional recorded channels

Counterplay:
- replay timeline is visible
- safe intervals exist
- players can destroy temporal anchors

### 3. Worldroot Dominion
**Class:** Primordial Warden
Rapidly grows a temporary traversal/fortification network from authored spawn nodes: roots, bridges, shelters, launch vines, healing groves, and entangling lanes.

Upgrades:
- Mythic: one grove
- God: linked grove network
- Absolute: adaptive fortress ecology
- Transcendent synergy: Genesis Engine can absorb Worldroot modules

Counterplay:
- fire/corruption archetypes can prune structures
- growth nodes can be attacked
- total active structure count is capped

### 4. Black-Sun Coronation
**Class:** Eclipse Sovereign
Creates a moving eclipse domain that changes visibility, enemy perception pressure, shield regeneration rules, and marked-target behavior.

Upgrades:
- Mythic: stationary eclipse
- God: moving eclipse
- Absolute: eclipse phases cycle through authored doctrines
- Transcendent synergy: Reality Engine can select one eclipse law as a temporary world parameter

Counterplay:
- luminous objectives weaken the eclipse
- domain is bounded
- boss ultimate attacks remain protected

### 5. Pantheon Engine
**Class:** Ascendant
Temporarily loads reduced versions of mastered class signatures into a rotating ability wheel.

The skill rewards actual account mastery rather than granting unearned powers.

Upgrades:
- Mythic: two borrowed signatures
- God: three
- Absolute: adaptive rotation based on encounter
- Transcendent: Pantheon Authority exposes the complete mastered set under strict duration/resource limits

Counterplay:
- borrowed skills are weaker than native-class versions
- rotation timing is fixed/telegraphed
- cannot duplicate protected Transcendent Authorities

## Skill Production Requirements
Every major skill must specify:
- activation state
- valid targets
- resource cost
- cooldown
- cancellation rules
- interruption behavior
- network authority assumptions
- persistent effects
- cleanup path
- visual telegraph
- audio telegraph
- accessibility fallback
- boss protection interactions
- performance cap
