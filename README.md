# AEONFALL

Dedicated source-of-truth repository for the AEONFALL UEFN/Fortnite world project.

## Scope
- 800+ original advanced content entities
- original weapons, armor, monsters, wildlife, factions, hireable NPCs, bosses, vehicles, skills, crafting, progression, world events, and endgame systems
- escalating rarity from Common through Transcendent Zero
- data-driven Verse architecture with strong performance, streaming, and persistence discipline

## Rule
This repository is AEONFALL-only. No ICARUS, trading, or unrelated project content belongs here.
