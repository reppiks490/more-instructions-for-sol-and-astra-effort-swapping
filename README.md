# AEONFALL

Dedicated source-of-truth repository for the AEONFALL UEFN/Fortnite world project.

## Start building in UEFN

Follow [the Windows UEFN setup guide](docs/UEFN_STARTER.md). The starter includes
18 original dungeon modules, a 593-placement Ossuary Exchange level plan,
GLB/OBJ exports, a landscape heightmap, a safe source installer, and an editor
assembly script. Open [the offline 3D preview](assets/source/ossuary_starter/preview.html)
or [the layout plan](assets/source/ossuary_starter/layout_plan.svg) to inspect it.

The Verse source now includes five-tier horde ecology, canonical boss/event
directors, queued typed events, and guarded ability transactions. Automated
checks cover source structure, authored policy, generated geometry and installer
behavior. Actual UEFN project creation, Verse compilation, Creative-device
bindings and Fortnite playtesting remain editor work; this repository does not
claim a compiled or published island.

## Scope
- 800+ original advanced content entities
- original weapons, armor, monsters, wildlife, factions, hireable NPCs, bosses, vehicles, skills, crafting, progression, world events, and endgame systems
- escalating rarity from Common through Transcendent Zero
- data-driven Verse architecture with strong performance, streaming, and persistence discipline

## Rule
This repository is AEONFALL-only. No ICARUS, trading, or unrelated project content belongs here.
